# Openfy v10 + v11 — Mod Hub e extensões seguras

## v10: Mod Hub (local)
- Página Mod Hub na navegação.
- Catálogo integrado com skins oficiais, pesquisa, filtros e estados de ativação.
- Ativação de skins usando o mecanismo de temas já existente.
- Catálogo **local**: sem servidor, contas, downloads remotos ou avaliações reais.

## v11: Extensões oficiais
- Focus Mode: oculta painel lateral de reprodução.
- Compact Player: reduz a barra do player.
- Calm Motion: reduz transições e animações.
- Estado de extensões persistido no localStorage.
- Sem carregamento ou execução de JavaScript de terceiros. Sistema de plugins externos permanece como evolução futura e precisará de sandbox/permissões.

## Teste
`npm install` e `npm run dev`. Entre em Mod Hub pela barra lateral. Teste filtros, ativação e reinício do aplicativo para verificar persistência.
