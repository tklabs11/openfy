# Openfy v18 + v19 — Global Search

- Busca fixa na barra superior em todas as páginas.
- Sugestões e resultados atualizados após pausa na digitação (450 ms).
- Enter confirma a pesquisa; Ctrl+K foca a busca.
- Histórico local de até 8 pesquisas confirmadas, com opção de limpar.
- Remove botões redundantes de busca da navegação.
- Mantém player, temas, Mod Hub e plugins sem alterações.

## Teste
`npm install`, `npm run typecheck`, `npm run dev`.

Observação: pesquisas digitadas são enviadas às fontes online já configuradas no Openfy.
