# Openfy v8 + v9 — entrega combinada

## v8 — Identidade e interface
- Identidade escura Openfy com acento azul elétrico, painéis com contornos sutis, foco visível e interações refinadas.
- Ajustes responsivos para janelas estreitas e organização dos painéis.
- Nova entrada **Temas & Mods** na navegação lateral.

## v9 — Theme Engine
- Quatro skins integradas: Midnight Blue, Forest Pulse, Neon Violet e Amber Studio.
- Aplicação instantânea e persistência local da escolha.
- Editor visual de cores, arredondamento e densidade.
- Exportação e importação de temas em JSON, com validação de formato e tamanho.
- Galeria local pronta para futura integração com catálogo comunitário.

**Importante:** a galeria ainda NÃO é um marketplace online: não há contas, avaliações, publicação ou download remoto. Nenhum plugin executável é carregado. Os temas são dados de configuração, não código executável.

## Como testar
1. Extraia o ZIP e entre na pasta `openfy`.
2. Execute `npm install` e `npm run dev` (ou o BAT fornecido).
3. Abra **Temas & Mods**, aplique temas, personalize, exporte e reimporte.

Os dados anteriores da biblioteca não são intencionalmente modificados. Faça backup dos seus dados locais antes de atualizações grandes.
