# Código de conduta

O Openfy busca uma comunidade acolhedora e colaborativa.

Trate outras pessoas com respeito. Não são aceitos assédio, discriminação, ameaças ou exposição de dados privados. Críticas técnicas são bem-vindas quando construtivas.

Mantenedores podem moderar discussões e contribuições que violem essas diretrizes. Para denúncias, use contato privado dos mantenedores.
