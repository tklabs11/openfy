# Segurança

Não publique detalhes de vulnerabilidades exploráveis em issues públicas.

Para reportar uma falha, entre em contato com os mantenedores por um canal privado indicado no perfil do repositório. Se o GitHub Private Vulnerability Reporting estiver habilitado, prefira esse recurso.

Inclua versão, sistema operacional, passos para reproduzir e impacto esperado. Nunca anexe credenciais reais.
